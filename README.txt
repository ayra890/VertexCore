# VertexCore Website

A professional dark cloud-infrastructure / VPS landing page built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Local SVG assets in `images/`

## Folder structure
VertexCore/
  index.html
  css/
    style.css
  js/
    script.js
  images/
    logo.svg
    hero-servers.svg
    dashboard.svg
    network.svg
    security.svg
    cloud.svg

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Upload the whole folder to your repository, keeping the folder structure unchanged. Your repository should have `index.html` at the root.
